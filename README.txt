PANDUAN DRAGON SPEEDRUN WEBSITE

1. Buka index.html menggunakan aplikasi editor teks.
2. Cari dua baris SUPABASE_URL dan SUPABASE_PUBLISHABLE_KEY.
3. Ganti placeholder dengan Project URL dan Publishable key milikmu.
4. Simpan file.

Jangan pernah memasukkan Secret key atau service_role key.

Fitur awal: daftar/login, profil XP/rank, leaderboard, kirim waktu manual berstatus Pending, dan riwayat.

Catatan: website belum membaca waktu Minecraft otomatis. Hasil harus diverifikasi admin. XP tidak bertambah dari pengiriman Pending. Jika konfirmasi email aktif, pemain harus konfirmasi email sebelum login.
